# Assistente Energia SENAI — PWA

## Como usar no computador
1. Extraia a pasta.
2. Para testar localmente, rode um servidor HTTP simples dentro da pasta:
   - Python: `python -m http.server 8080`
3. Abra `http://localhost:8080` no Chrome/Edge.
4. Clique em **Instalar aplicativo** quando o navegador oferecer.

## Como usar no smartphone
1. Publique a pasta em Vercel, Netlify ou GitHub Pages.
2. Abra o endereço no Chrome (Android) ou Safari (iPhone).
3. Android: Menu > **Instalar app** / **Adicionar à tela inicial**.
4. iPhone: Compartilhar > **Adicionar à Tela de Início**.

## O que já está incluído
- Dashboard tecnológico
- Cards de cursos e alertas
- Pesquisa local
- Atalhos para Google Planilhas, Calendar, Gmail e ChatGPT
- Notas rápidas salvas no dispositivo
- Instalação como PWA
- Funcionamento offline do painel-base
